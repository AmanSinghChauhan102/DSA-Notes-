Queue Data Structure

First-In-First-Out (FIFO) Principle

Understanding Queues

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. It works like a line of people waiting for a service, where the person who arrives first is served first.

Example

Imagine a ticket counter at a movie theater. People arrive and join the queue, waiting for their turn to buy tickets. The person who arrives first is served first, and the person who arrives last is served last.

Permissible Operations on Queue

The following are the permissible operations on a queue:

Enqueue

Adding an element to the end of the queue. (e.g., a person joining the line)

Dequeue

Removing an element from the front of the queue. (e.g., a person buying a ticket and leaving the line)

Peek

Viewing the element at the front of the queue without removing it. (e.g., checking who is next in line)

IsEmpty

Checking if the queue is empty. (e.g., checking if there is anyone in line)

IsFull

Checking if the queue is full. (e.g., checking if the line is full and no more people can join)

Simplest Example

Let's consider a simple example of a queue with 5 elements:

Initial Queue: Empty

1. Enqueue 2: Queue = [2]

2. Enqueue 5: Queue = [2, 5]

3. Enqueue 8: Queue = [2, 5, 8]

4. Peek: Front element is 2

5. Dequeue: Queue = [5, 8]

6. Dequeue: Queue = [8]

7. IsEmpty: Queue is not empty

8. IsFull: Queue is not full (assuming maximum size is 5)

This example illustrates the basic operations that can be performed on a queue.

Queue Implementation in C

#include <stdio.h>
#include <stdlib.h> // For exit()

#define MAX_SIZE 5 // Define the maximum size of the queue

// Global variables
int queue_array[MAX_SIZE];
int front = -1;
int rear = -1;

// Function prototypes
void enqueue(int value);
void dequeue();
void display();

int main() {
    int choice, value;

    while (1) { // Infinite loop for the menu
        printf("\n--- QUEUE MENU ---\n");
        printf("1. Enqueue (Add an element)\n");
        printf("2. Dequeue (Remove an element)\n");
        printf("3. Display the queue\n");
        printf("4. Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                printf("Enter the value to add: ");
                scanf("%d", &value);
                enqueue(value);
                break;
            case 2:
                dequeue();
                break;
            case 3:
                display();
                break;
            case 4:
                printf("Exiting the program.\n");
                exit(0); // Terminate the program
            default:
                printf("Invalid choice! Please try again.\n");
        }
    }

    return 0;
}

/**
 * @brief Adds an element to the rear of the queue.
 * @param value The integer value to be added.
 */
void enqueue(int value) {
    // 1. Check if the queue is full
    if (rear == MAX_SIZE - 1) {
        printf("Error: Queue is full (Overflow)!\n");
        return;
    }
    
    // 2. If the queue is empty, set front to 0
    if (front == -1) {
        front = 0;
    }

    // 3. Increment rear and add the element
    rear = rear + 1;
    queue_array[rear] = value;
    printf("%d was successfully enqueued.\n", value);
}

/**
 * @brief Removes the element from the front of the queue.
 */
void dequeue() {
    // 1. Check if the queue is empty
    // The condition 'front > rear' handles the case where all elements have been dequeued.
    if (front == -1 || front > rear) {
        printf("Error: Queue is empty (Underflow)!\n");
        // Optional: Reset queue if it becomes empty
        if (front > rear) {
            front = rear = -1;
        }
        return;
    }

    // 2. Remove the element by incrementing the front pointer
    printf("%d was dequeued from the queue.\n", queue_array[front]);
    front = front + 1;
}

/**
 * @brief Displays all the elements currently in the queue.
 */
void display() {
    // 1. Check if the queue is empty
    if (front == -1 || front > rear) {
        printf("Queue is empty.\n");
        return;
    }

    // 2. Print all elements from front to rear
    printf("Queue elements are: ");
    for (int i = front; i <= rear; i++) {
        printf("%d ", queue_array[i]);
    }
    printf("\n");
}

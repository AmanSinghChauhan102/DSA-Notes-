Algorithm for Converting Infix to Postfix

  1. Initialize an empty stack and an empty output string.
  2. Iterate through the infix expression from left to right.
  3. If the character is an operand (letter or number), add it to the output string.
  4. If the character is an operator (+, -, *, /, etc.):
    • If the stack is empty or the top of the stack has lower precedence, push the operator onto the stack.
    • Otherwise, pop operators from the stack and add them to the output string until the stack is empty or the top of the stack has lower precedence, then push the current operator onto the stack.
  5. If the character is a left parenthesis, push it onto the stack.
  6. If the character is a right parenthesis, pop operators from the stack and add them to the output string until a left parenthesis is encountered, then discard the left parenthesis.
  7. After iterating through the entire infix expression, pop any remaining operators from the stack and add them to the output string.

Example

Let's convert the infix expression: A + B * C

1. A is an operand, so add it to the output string: A

2. + is an operator, so push it onto the stack: [+

3. B is an operand, so add it to the output string: A B

4. * is an operator with higher precedence than +, so push it onto the stack: [+, *

5. C is an operand, so add it to the output string: A B C

6. Pop operators from the stack and add them to the output string:

  • Pop * and add it to the output string: A B C *
  • Pop + and add it to the output string: A B C * +

The postfix expression is: A B C * +

Algorithm for Converting Infix to Prefix/Polish Notation

  1. Reverse the infix expression.
  2. Convert the reversed infix expression to postfix notation using the standard infix-to-postfix algorithm.
  3. Reverse the postfix expression to get the prefix notation.

Infix-to-Postfix Algorithm

  1. Initialize an empty stack and an empty output string.
  2. Iterate through the infix expression from left to right.
  3. If the character is an operand, add it to the output string.
  4. If the character is an operator:
    • If the stack is empty or the top of the stack has lower precedence, push the operator onto the stack.
    • Otherwise, pop operators from the stack and add them to the output string until the stack is empty or the top of the stack has lower precedence, then push the current operator onto the stack.
  5. If the character is a left parenthesis, push it onto the stack.
  6. If the character is a right parenthesis, pop operators from the stack and add them to the output string until a left parenthesis is encountered, then discard the left parenthesis.
  7. After iterating through the entire infix expression, pop any remaining operators from the stack and add them to the output string.

1. C is an operand, so add it to the output string: C

2. * is an operator, so push it onto the stack: [*

3. ( is a left parenthesis, so push it onto the stack: [*, (

4. B is an operand, so add it to the output string: C B

5. + is an operator, so push it onto the stack: [*, (, +

6. A is an operand, so add it to the output string: C B A

7. ) is a right parenthesis, so pop operators from the stack and add them to the output string: C B A +

8. Pop the remaining operator from the stack and add it to the output string: C B A + *
